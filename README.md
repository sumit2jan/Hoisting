# JavaScript Hoisting Notes

A clean, interview-focused single-page guide for understanding JavaScript hoisting. The page explains the execution phases, `var`, `let`, `const`, function declarations, function expressions, classes, Temporal Dead Zone, and common interview questions with examples.

## What is included

- Hindi-friendly explanations with practical JavaScript examples
- Creation phase vs execution phase breakdown
- `var`, `let`, and `const` hoisting behavior
- Temporal Dead Zone examples
- Function declaration vs function expression behavior
- Class hoisting behavior
- Quick reference table for interview revision
- Best practices and memory hooks

## How to view

Open `Index.html` directly in any modern browser.

No package install, build step, or local server is required.
